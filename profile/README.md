# Peerframe

We believe creativity belongs to everyone. Peerframe builds open tools that bring AI into the way people think, work, and create, helping more ideas become real. Our first project, **OpenBot**, is a space for people and Bots to work side by side.

我们相信，创造力属于每一个人。Peerframe 构建开放的工具，让 AI 融入人的思考与协作，帮助更多想法成为现实。我们的第一个作品 **OpenBot**，是一个人与 Bot 并肩工作的空间。

## Contribute / 参与贡献

Report bugs and propose features through [OpenBot Issues](https://github.com/Peerframe/openbot/issues). Before sending a pull request, read the [contribution guide](https://github.com/Peerframe/openbot/blob/main/CONTRIBUTING.md). For website and documentation issues, use [website Issues](https://github.com/Peerframe/openbot-website/issues).

产品问题与功能建议请提交至 [OpenBot Issues](https://github.com/Peerframe/openbot/issues)；参与开发请先阅读[中文贡献指南](https://github.com/Peerframe/openbot/blob/main/CONTRIBUTING.zh-CN.md)。官网与手册问题请提交至[网站 Issues](https://github.com/Peerframe/openbot-website/issues)。

Report OpenBot vulnerabilities privately by following the [security policy](https://github.com/Peerframe/openbot/blob/main/SECURITY.md). Please do not include credentials or sensitive details in public issues.

OpenBot 安全漏洞请按[安全政策](https://github.com/Peerframe/openbot/blob/main/SECURITY.md)私下报告，请勿在公开 Issue 中发布密钥或敏感细节。
