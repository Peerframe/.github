# Peerframe

我们开发促进人与 AI 协作的开源工具。目前专注于 **OpenBot**：一个可自托管的 Bot 工作区，让 Bot 保留职责与记忆，在频道中分工协作，并交付可用文件。

## 组织成员，从这里开始

**[协作手册 Handbook](https://github.com/Peerframe/handbook)** · **[GitHub 新手指南](https://github.com/Peerframe/handbook/blob/main/docs/github-guide.md)** · [图文操作手册 PDF](https://github.com/Peerframe/handbook/blob/main/docs/github-guide.pdf) · [任务看板 Roadmap](https://github.com/orgs/Peerframe/projects/1)

第一次参与协作，先读新手指南；查入组、权限和交接流程，进入 Handbook；查看任务进度，打开 Roadmap。

这些成员入口与 Skills 为私有资源，需要登录有访问权限的 GitHub 账号。出现 404 时，先确认账号、邀请和团队授权；链接本身不会授予访问权限。

## 参与贡献与反馈

- 产品问题与功能建议：[OpenBot Issues](https://github.com/Peerframe/openbot/issues)。参与开发前，请阅读[中文贡献指南](https://github.com/Peerframe/openbot/blob/main/CONTRIBUTING.zh-CN.md)。
- 官网与 **OpenBot 产品使用文档**的问题：[网站 Issues](https://github.com/Peerframe/openbot-website/issues)。
- **组织协作手册、教程与成员流程**的问题：[Handbook Issues](https://github.com/Peerframe/handbook/issues)，需要私有仓库访问权限。
- OpenBot 安全漏洞请按[安全政策](https://github.com/Peerframe/openbot/blob/main/SECURITY.md)私下报告，请勿在公开 Issue 中发布密钥或敏感细节。

Open-source tools for human–AI collaboration. We build **OpenBot**, a self-hosted workspace where Bots remember their roles, collaborate in channels, and deliver useful files.

Explore the [product source](https://github.com/Peerframe/openbot), [website](https://peerframe.github.io/openbot-website/), [installation guide](https://peerframe.github.io/openbot-website/manual/installation/), [releases](https://github.com/Peerframe/openbot/releases) and [interactive demo](https://peerframe.github.io/openbot-website/demo/index.html). Report product bugs through [OpenBot Issues](https://github.com/Peerframe/openbot/issues), website and product-documentation issues through [website Issues](https://github.com/Peerframe/openbot-website/issues), and internal collaboration-guide issues through [Handbook Issues](https://github.com/Peerframe/handbook/issues). Read the [contribution guide](https://github.com/Peerframe/openbot/blob/main/CONTRIBUTING.md) before proposing code changes. Report vulnerabilities privately following the [security policy](https://github.com/Peerframe/openbot/blob/main/SECURITY.md).
